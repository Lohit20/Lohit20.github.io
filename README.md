# Lohit Ashwa Vaswani — Portfolio

Static site for GitHub Pages.

## Quick start
1. Create a public repo named `Lohit20.github.io` (replace with your GitHub username).
2. Put these files at the repo root and push.
3. Visit `https://<your-username>.github.io`.

## Customize
- Edit `index.html` for content.
- Replace `assets/img/avatar.svg` with your photo.
- Update resume file at `assets/Lohit-Ashwa-Vaswani-Resume.pdf`.
