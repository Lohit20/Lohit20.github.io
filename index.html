QLoRA Llama-2 7B: Single GPU Fine-Tuning on Clinical Text

BSc Final Year · QLoRA · PEFT · Llama-2 7B · Trade for Sight
Overview

Fine-tuned Llama-2 7B on financial and clinical domain text using QLoRA on a single consumer GPU, dramatically reducing memory requirements while retaining reasoning quality for the Trade for Sight RAG assistant.

Architecture & training decisions
  • QLoRA (4-bit NF4 quantisation and LoRA adapters) reducing GPU memory from 28 GB to 6 GB, an 78% reduction
  • PEFT adapter layers targeting attention projection matrices for efficient domain adaptation
  • Trained on structured financial narratives generated from SQL market data for grounded, CoT-style outputs
  • Integrated with Pinecone and LlamaIndex RAG layer, with fine-tuning and retrieval complementing each other
